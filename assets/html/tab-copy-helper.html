# 标题 链接 操作
还没有数据，从这里开始：
1. 在 Chrome 中安装 Tab Copy Options 插件
2. 打开需要整理的标签页，用插件复制（推荐 JSON 格式）
3. 粘贴到上方输入框，点击「解析数据」
4. 编辑、去重、筛选后按需复制导出
