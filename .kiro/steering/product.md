# Product: WebStack

WebStack (webstack.cc) is a static website navigation/bookmark directory aimed at designers. It curates links to UI design resources, inspiration galleries, design tools, fonts, mockups, tutorials, and UED team blogs.

The site is bilingual — Chinese (`cn/`) and English (`en/`) — with an auto-redirect on the root `index.html` based on the browser's language setting.

It is a pure front-end, no-backend project intended to be self-hosted or deployed via static hosting (e.g., GitHub Pages). There is no build step, no package manager, and no server-side logic.

The primary audience is UI/UX designers and product managers looking for curated design resources.
